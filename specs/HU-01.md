# HU-01 - Administrar inventario

## Historia de usuario
Como responsable de inventario quiero registrar productos y consultar existencias para saber qué cantidades puedo comprometer.

## Contratos
POST /products, GET /products

## Criterios de aceptación verificables
Nombre único no vacío; stock entero >= 0; duplicados devuelven 409.
