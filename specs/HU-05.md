# HU-05 - Sugerencias asistidas y validación

## Historia de usuario
Como supervisor quiero ver recomendaciones justificadas y aprobarlas o rechazarlas para mantener supervisión humana.

## Contratos
POST /requests/{id}/suggest, POST /decisions/{id}/review, GET /decisions

## Criterios de aceptación verificables
Sugerencia explicable por reglas; persiste texto y justificación; revisión explícita con nombre y booleano; sugerencia nunca ejecuta acciones.

## Pruebas vinculadas
test_suggestion_and_review

## Regla de SDD
Revisar este archivo y aprobarlo por una persona del equipo antes de cambiar el código.

## Registro de revisión de especificación
- Estado: propuesta para revisión del equipo; no existe aprobación acreditada.
- Revisor: por registrar tras revisión efectiva.
- Fecha: por registrar tras revisión efectiva.
- Evidencia: enlace al commit o PR real.
- Nota de secuencia: la especificación fue generada junto con el prototipo; no se afirma una aprobación previa.
