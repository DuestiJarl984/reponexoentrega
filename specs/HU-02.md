# HU-02 - Registrar solicitudes

## Historia de usuario
Como cliente quiero registrar una solicitud para pedir cantidades específicas de un producto.

## Contratos
POST /requests, GET /requests

## Criterios de aceptación verificables
El producto debe existir; cantidad entera > 0; estado inicial PENDIENTE.

## Pruebas vinculadas
